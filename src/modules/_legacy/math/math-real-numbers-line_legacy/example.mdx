# Operasi Bilangan Riil & Garis Bilangan

Modul ini mengimplementasikan visualisasi spasial 1D untuk bilangan riil kontinu.

## Penggunaan Komponen

```tsx
import { Canvas } from "@/modules/math/math-real-numbers-line/Canvas";
import { Controls } from "@/modules/math/math-real-numbers-line/Controls";
import { KaTeXFormula } from "@/modules/math/math-real-numbers-line/KaTeXFormula";

export default function DemoPage() {
  const [state, setState] = useState({
    point1: 3,
    point2: -4,
    scaleFactor: 2,
    sqrtN: 2,
    zoomLevel: 1,
    distribA: 3,
    distribB: 4,
    distribC: 2,
  });

  return (
    <div>
      <KaTeXFormula state={state} />
      <Canvas state={state} />
      <Controls state={state} onChange={setState} onReset={() => {}} />
    </div>
  );
}
```

## Fitur Utama

1. **Vektor Translasi 1D:** Menunjukkan panah perpindahan $\Delta x = B - A$ dan jarak fisik $|B - A|$.
2. **Dilatasi Skala:** Memperagakan perkalian dan pembalikan arah 180° $(-1) \times (-1) = +1$.
3. **Rebahan Busur Akar:** Geometri hipotenusa segitiga siku-siku Pythagoras untuk bilangan irasional $\sqrt{N}$.
4. **Zoom Mikro:** Eksplorasi kerapatan pecahan dan desimal.
